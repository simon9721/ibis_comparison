# Presentation Templates

`mst_green_16x9.pptx` is the reusable local copy of the lab presentation style
originally supplied as `0710_Simon_IBIS.pptx`. Keep the slide masters, layouts,
theme, title treatment, and green visual language here; keep project content in
separate generator scripts.

The reusable Python API is documented in `tools/presentation_kit/README.md`.
