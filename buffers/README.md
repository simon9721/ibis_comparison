# buffers/

Source data for the buffers under study — netlists, transistor model cards and
vendor IBIS files. These are **inputs**, not outputs: nothing here is generated by
a script in this repo.

| directory | what it holds |
|---|---|
| `ex2/` | the layout-extracted ex2 output buffer (`buffer.sp`) and its BSIM model card (`hspice.mod`) |
| `inv_chain/` | the eight-stage tapered inverter chain and its transistor library |
| `models/` | io_buf (`io_buf.sp`), its model cards and vendor `.ibs` files |

Buffer *variants* are generated from these into `results/`, not stored here —
see `scripts/make_inv_chain_variants.py` and `scripts/make_ex2_variants.py`.

Note the two io_buf model cards are not interchangeable: `hspice_ngspice.mod`
sets RDSW=0 and is about 12% stronger than the stock `hspice.mod`. A model has to
be simulated against the card it was characterised from.
