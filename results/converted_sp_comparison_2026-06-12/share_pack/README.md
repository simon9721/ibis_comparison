# Converted SP Comparison Pack

Generated: 2026-06-12

This folder contains real converted SPICE `.sp` models generated from the same source Touchstone files so the full vector-fit and reduced-model approaches can be compared side by side.

## Important Scope Notes

- The `vector_fit/` files are scikit-rf `VectorFitting` exports.
- The `reduced_model/` files are custom Touchstone-derived reduced macromodels from this repo.
- The reduced models use scikit-rf only to read the Touchstone data; they do not use scikit-rf vector fitting or scikit-rf SPICE export.
- Reduced `.s4p` models are scoped to matched 50 ohm RX-through behavior. They are not full 4-port replacements.
- These files were generated as model examples with `--skip-ngspice`, so this pack is for model structure comparison. Use the main study folder for smoke/audit validation results.

  --skrf-target "$env:TEMP\ibis_skrf_target" `

## What To Compare

Vector-fit models:

- Full port matrix representation.
- More controlled-source/state-network content.
- Generated by scikit-rf.
- Better aligned with long-term full multiport replacement goals.

Reduced models:

- Much smaller and easier to read.
- Explicit delay elements plus RC/tail/ringing branches.
- Generated by custom code from the dominant path.
- Better aligned with the current matched 50 ohm RX-through objective.
- Not a complete S-matrix replacement.
