# ex2 variants

Generated by `scripts/make_ex2_variants.py` -- the same
axes swept on inv_chain, applied to ex2's extracted device widths.

| variant | what changed |
|---|---|
| `base` | unchanged reference |
| `weak` | output stage at half width |
| `skewp` | output PMOS at half width |
| `slowpre` | predriver at half width |

**`base`** — Identical to the shipped ex2. Built through the same generator so the reference and the variants differ only in the silicon.

**`weak`** — Halves both output devices: weaker drive and a slower edge into the same load, with the timing structure untouched.

**`skewp`** — Halves only the pullup, so rise slows and fall does not. On inv_chain this inflated max|Ku| while leaving Kd untouched; this repeats it on a real extracted layout.

**`slowpre`** — Weakens the three predriver stages, so n4 swings more slowly and the output onset is delayed -- ex2's analogue of inv_chain's stage count, which is the quantity the command layer represents.

The open-drain variant is generated separately by
`scripts/make_ex2_opendrain_variant.py`; removing the pullup is a
structural change rather than a width scaling.
