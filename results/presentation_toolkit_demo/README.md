# Reusable Presentation Toolkit Demo

`green_template_toolkit_demo.pptx` is generated by:

```powershell
$env:PYTHONPATH = ".codex_deps/presentation/python;."
py -3.14 examples/presentation_toolkit/build_demo_deck.py
```

The demo proves that the checked-in green template, presenter notes, process
diagrams, code blocks, and cached MathJax equations can all be generated through
the project-neutral `tools.presentation_kit` API.

`slides/` contains the PowerPoint-rendered PNG inspection output from the latest
verification run.
